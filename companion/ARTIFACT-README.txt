PC Check Companion — private beta

This unsigned build is for owner-controlled Windows E2E only.
It does not download software, change Defender, alter PowerShell policy,
change VPN settings, or send the generated report anywhere.

Run PC-Check.exe. Reports are written to the Reports folder beside the app,
with Documents as a fallback if that location is read-only.

Do not publish this beta on the website until Windows 10/11 E2E, Defender,
SmartScreen, report accuracy, signing, and final SHA-256 are verified.
