Перед копированием на флешку

1. Скачай дома. 2. Проверь файл Защитником Windows. 3. Для EXE — правой кнопкой → Свойства → Цифровые подписи → Сведения: должно быть «Цифровая подпись действительна». ZIP сам может быть не подписан — проверь EXE внутри после распаковки. 4. Если автор публикует SHA-256, сравни его через PowerShell: Get-FileHash .\имя-файла.exe -Algorithm SHA256. Нет подписи и опубликованного хэша — файл не считается проверенным только из-за названия. 5. Подпиши папку датой проверки.

Шаги 01–04 · на встрече

Иди сверху вниз.
Не перескакивай.

Ориентир≈30минут или дольше
  1. 0–5 мин

    Осмотр до включения

    Сфотографируй общий вид, наклейку блока питания, питание видеокарты, слоты RAM/M.2 и серийные номера. Проверь пломбы, коррозию, следы жидкости, гари и грубого ремонта. Сам блок питания не вскрывай и ничего внутри него не измеряй.

    Стоп: запах гари, потемнения, жидкость, искры, оголённые провода или продавец запрещает открыть корпус.

    Доказательство5–7 фото корпуса
  2. 5–10 мин

    Сверка состава

    CPU-Z: CPU, Mainboard, Memory, по очереди каждый Slot в SPD. GPU-Z: название, Memory Size и Bus Interface; нажми «?» и запусти Render Test — шина должна перейти из режима простоя.

    Торг: одна планка RAM вместо двух, меньший объём/частота, другая плата или накопитель. Несовпадение дорогого CPU/GPU — остановка сделки.

    Доказательство6 скриншотов
  3. 10–15 мин

    Каждый накопитель

    В CrystalDiskInfo переключи диски стрелками. Сними Health Status, температуру, часы и SMART. Уточни, какой диск входит в продажу.

    Стоп или цена немедленной замены: Bad/Caution; для HDD особенно 05, C5 или C6 больше нуля, для SSD — критически малый остаток ресурса. Не пройдено: Unknown, USB или RAID требуют отдельной диагностики и не считаются чистым результатом. Good тоже не гарантирует будущую исправность.

    Доказательство1 кадр на диск
  4. 15–27 мин

    Короткая контролируемая нагрузка

    Запомни время старта. Спроси согласие продавца, закрой игры и лишние программы, открой HWiNFO в режиме Sensors. В OCCT: 3D на 3 минуты, CPU на 4 минуты и Memory на 4 минуты. Следи за ошибками, температурами и Maximum. Не запускай Power и не меняй напряжения.

    Стоп сразу: артефакты, ошибка OCCT, BSOD, ребут, выключение, запах или резкий треск вентилятора. Устойчивый или повторяющийся Thermal Throttling на штатных настройках — красный флаг; единичный пик перепроверь. Power/Current Limit сам по себе не означает перегрев.

    ДоказательствоOCCT + HWiNFO Max
  5. 27–30 мин

    Порты и финальная сверка

    Проверь USB флешкой, звук, Ethernet/Wi‑Fi и заявленные видеовыходы. Затем: Просмотр событий → Журналы Windows → Система → Фильтр текущего журнала → источник WHEA-Logger. Журнал не очищай: сравни время событий с записанным временем старта теста.

    Стоп: новые WHEA-Logger события в интервале твоего теста. Старые записи за другую дату — контекст, но не результат текущей проверки.

    Торг: неработающий вторичный порт, шумный вентилятор, слабая батарейка CMOS. Неисправный основной видеовыход или сетевой адаптер — только если готов ремонтировать.

    ДоказательствоФото портов + итог

Шаг 05 · решение

Не гадай.
Сверь результат.

Короткий тест означает только «явных проблем не найдено». Он не даёт гарантии и программами нельзя доказать исправность блока питания.

ПРОДОЛЖИТЬ

Всё совпало

  • Состав как в объявлении
  • SMART без тревог
  • OCCT без ошибок и сбоев
  • Порты работают
  • Есть все доказательства
ТОРГ

Проблема оценима

  • Одна планка RAM
  • Caution — с ценой замены диска
  • Шумный вентилятор
  • Не работает вторичный порт
  • Модель БП слабее обещанной
СТОП

Риск неизвестен

  • Состав подменён
  • Артефакты, ошибки, BSOD
  • Bad / пропадающий диск
  • SMART Unknown без отдельной проверки
  • Гарь, коррозия, жидкость
  • Не дают проверить или торопят
